# ai-video-style-remake

把任意视频片段重绘成任意风格，或做成外语版二创短视频 —— 一份给 AI 助手用的操作手册。

## 这是什么

这不是一篇给人读的教程，而是**给 AI 读的 skill**。装进你的 AI 助手后，你不需要记住任何步骤，只要说一句「帮我把这段视频重绘成赛博朋克」，它就会按这套流程陪你做完：

- 先问清目标、素材、预算时限，不会上来就瞎跑
- 提醒你按剧情节点切段，而不是按秒硬切
- 用四层递进结构帮你磨提示词，最后交付成一个文件
- 在你该重跑而不是死改的时候拉住你
- 收尾阶段给出剪辑清单

它固化的是**判断标准**，不只是操作步骤。

## 三条铁律

1. **喂原片重绘**，不用纯文字生成 —— 只有这样才能保住本人的脸、动作和节奏
2. **AI 负责把画面生出来，精细活你自己做** —— 冗帧、乱码台词、音画不同步，回剪辑软件几十秒解决
3. **全程锁定同一套设置** —— 中途换模型会让前后段串味

## 六步闭环

备料切段（先做单段样片） → 定立意 → 选平台与模型 → 磨提示词（四层） → 重绘迭代（改不动就重跑） → 剪辑收尾

开工前会先问清你的目标、素材、预算与时限，再推荐工具和模型 —— 不会替你拍板。

## 安装

把整个 `ai-video-style-remake` 文件夹放到你的 AI 助手技能目录下即可。常见的用户级路径：

```
~/.workbuddy/skills/ai-video-style-remake/
```

放好后重启或刷新技能列表，即可以对话方式调用。
